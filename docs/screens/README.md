## Как перенести в Figma

1. figma.com → **New design file**, назвать «MeetSpace — макеты».
2. Перетащить все PNG из этой папки на холст.
3. Выделить картинку → **Ctrl+Alt+G** (Frame selection), чтобы каждый экран стал отдельным фреймом, и переименовать фрейм как в таблице.
4. Расставить: в первом ряду экраны пользователя, во втором — администратора, справа — мобильные.
5. **Share** → «Anyone with the link can view» → ссылку вставить в README.
