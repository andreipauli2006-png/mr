# Сценарий демо-видео (до 5 минут)

Записывать экран: OBS Studio или Xbox Game Bar (Win+Alt+R). Разрешение 1920×1080, голос — за кадром.
Перед записью открыть https://meetspace-xgyx.onrender.com и подождать, пока сайт «проснётся».

| Время | Что на экране | Что говорить |
|---|---|---|
| 0:00–0:20 | Главная страница, каталог залов | «MeetSpace — сервис бронирования переговорных. Без входа можно посмотреть залы и их расписание». |
| 0:20–0:50 | Поиск «Альфа», фильтр «Мест от 10», удобство «Проектор», сортировка | «Поиск, фильтры и сортировка работают на сервере, есть пагинация». |
| 0:50–1:20 | Регистрация нового пользователя: сначала пустая форма (показать ошибки), потом заполнить | «Валидация на клиенте и на сервере. После регистрации пользователь получает роль “Гость”». |
| 1:20–1:50 | Гость открывает зал, выбирает слоты, отправляет заявку | «Бронь гостя уходит на подтверждение администратору». |
| 1:50–2:30 | Выход → вход за сотрудника `employee@meetspace.ru`. Бронь на свободное время. Попытка занять занятый слот — он недоступен | «Сотрудник бронирует сразу. Пересечения запрещены: и в интерфейсе, и на сервере, и в базе данных». |
| 2:30–2:50 | «Мои брони»: поиск, фильтр по статусу, отмена с подтверждением, экспорт в Excel | «Отмена — только с подтверждением. Брони выгружаются в Excel». |
| 2:50–3:40 | Вход за администратора. Дашборд → Заявки (подтвердить заявку гостя) → Управление залами (редактирование, загрузка фото) → Пользователи (сменить роль гостя на «Сотрудник») → Журнал | «Администратор подтверждает заявки, управляет залами и пользователями. Все действия пишутся в журнал». |
| 3:40–4:00 | Личный кабинет: профиль, смена пароля, история действий | «В личном кабинете — профиль, смена пароля и история». |
| 4:00–4:20 | Переключение тёмной темы; сузить окно до ширины телефона | «Тёмная тема и адаптивная вёрстка от 360 пикселей». |
| 4:20–4:50 | Swagger `/api/docs`, затем GitHub: вкладка Actions с зелёными проверками | «API документирован в OpenAPI. На каждый Pull Request CI запускает линтер, тесты и сборку». |
| 4:50–5:00 | Главная страница | «Спасибо за внимание». |
